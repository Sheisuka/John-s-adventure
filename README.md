# John's adventure 
## Истреби всех врагов и добудь майонез 
Игра состоит из 2 уровней, наполненных различными враждебными мобами: кетчуп-слизни, шипы, тренты, а также багами: баги коллизии, кривое расширение. Для прохождения необходимо добраться до лестницы, находящейся в конце 2 уровня. 


## Содержание py файлов в репозитории: 

- particles.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит класс необходимый 
при создании партиклов при передвижении игрока

- settings.py  
&nbsp;&nbsp;&nbsp;&nbsp;в этом файле происходит загрузка 
уровней

- utility.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит функцию, загружающую и обрабатывающую
изображения, находящиеся по переданному пути

- menu.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит классы таких меню как меню паузы, основное меню
а также стартовый экран и подсчёт результатов

- player.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит всё связанное с классом игрока:
анимации, передвижение получение и нанесение урона

- main.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит класс Game, отвечающий за смену уровней, меню и тп

- level.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит класс Level, ответственный за создание уровней, обработку столкновений

- other.py  
&nbsp;&nbsp;&nbsp;&nbsp;содержит классы окружения и врагов
